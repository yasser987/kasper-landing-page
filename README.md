# Kasper Landing Page

A responsive multi-section landing page built with semantic HTML and modern CSS. The project recreates the Kasper creative agency design while focusing on layout, responsiveness, accessibility, and maintainable styling.

## Features

- Responsive layouts for mobile, tablet, and desktop
- Semantic page structure
- Flexbox and CSS Grid layouts
- Reusable design variables and section styles
- Interactive hover and focus states
- Optimized local assets and web fonts

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Font Awesome

## Project Status

This project is currently undergoing a portfolio-quality review covering code structure, responsive behaviour, accessibility, SEO, performance, and documentation.
